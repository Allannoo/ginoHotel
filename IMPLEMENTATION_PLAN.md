# Горизонт — План реализации

> Платформа управления отелями и посуточной недвижимостью.
> Стек: **React 18 + TypeScript + Vite + Tailwind CSS + Framer Motion + Recharts + React Router v6 + React Query + Zustand + @dnd-kit**.
>
> ⚠️ Примечание: вместо устаревшего Create React App используется **Vite** — это современный стандарт (CRA deprecated с 2023). Стек React+TS остаётся идентичным.

---

- [x] Vite + React 18 + TypeScript (вместо устаревшего CRA)

    utils/          # Форматтеры, хелперы

## Моковые данные
Все данные генерируются в `src/mock/` детерминированно (seed-based) при загрузке приложения:
- **3 отеля** (Москва, СПб, Сочи) + **8 квартир** (разные адреса)
- **~50 номеров** в сумме (категории Standard/Deluxe/Suite/Family)
- **150+ броней** на ближайшие 60 дней (разные статусы и каналы)
- **80+ гостей** (РФ + СНГ + иностранцы, теги, история)
- **5 каналов** (4 подключённых + 1 ошибка для демо)
- **30+ задач** в Kanban (разные приоритеты и статусы)
- **6 сотрудников** с разными ролями

## Принципы кода
- TypeScript strict mode
- Все комментарии — на русском языке
- Компоненты — функциональные, hooks-only
- Стилизация — Tailwind + CSS-переменные (никаких inline-цветов)
- Никаких реальных API-запросов — только мок-провайдеры через `setTimeout` для имитации задержки
- Адаптив: мобильный (< 768px), планшет (768-1024px), десктоп (1024+)
