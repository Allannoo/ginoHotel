# Горизонт — конкурентный анализ и план развития функционала

Документ собран на основе исследования рынка PMS / Channel Manager / Booking
Engine — российских и зарубежных. Включает обзор конкурентов, 10 идей по
развитию того, что у нас уже есть, и 10 «must-have» функций, которых сейчас
в продукте нет.

> Версия: 1.0 · Май 2026

## 3. ❶ 10 идей развития существующего функционала

Эти идеи опираются на то, что **уже частично реализовано** в HotelIQ и
доводят его до уровня лидеров рынка.

### 1. AI Dynamic Pricing v2

> Сейчас есть статичные тарифы. Добавить ML-модель, которая каждое утро
> пересчитывает ADR по комнатам с учётом: загрузки на горизонте 90 дней,
> цен конкурентов (rate-shopping через Booking.com Demand API / RateGain),
> локальных событий (концерты, конференции — парсинг афиш), погоды.
> Интерфейс: график «рекомендованная vs текущая цена» с возможностью
> одной кнопкой применить рекомендации на 7/30/90 дней.

### 2. Channel Manager 2.0 с conflict resolution

> Сейчас есть подключение каналов в Settings (Booking, Ostrovok и др.).
> Доработать: 2-way sync в реальном времени через webhooks,
> детектирование «overbooking» (один номер продан в двух местах
> одновременно), мастер разрешения конфликтов с автопоиском компенсаций
> (апгрейд гостя, перевод в соседний номер, передача в партнёрский
> отель).

### 3. Multi-property Revenue Dashboard

> Сейчас финансовая аналитика по одному объекту. Сделать сводный экран
> сети: тепловая карта по всем объектам (occupancy + ADR + RevPAR),
> сравнение друг с другом, экспорт в один XLSX, дриллдаун по клику.

### 4. Guest Self-Service Portal (PWA)

> Сейчас гость не имеет личного кабинета. Сделать ссылку, которая
> приходит в SMS/Email после брони: цифровая регистрация (паспорт через
> камеру + распознавание), выбор времени заезда, заявка на трансфер,
> заказ дополнительных услуг, ранний check-in, оплата депозита.
> Экономит 5-10 минут на стойке регистрации.

### 5. Housekeeping Kanban c фото

> Сейчас в Tasks есть базовый to-do. Расширить в мобильный Kanban для
> горничной: «Грязный → В уборке → Готов к проверке → Чистый»,
> обязательные фото после уборки, чек-лист (8-12 пунктов: смена белья,
> ванная, мини-бар), время уборки, авто-эскалация если номер >30 минут
> в одном статусе.

### 6. Mobile-first приложение для ресепшена

> Сейчас интерфейс десктопный. Сделать PWA с быстрыми действиями:
> check-in одним свайпом, скан паспорта камерой, выписка с
> авто-формированием чека, push при новой брони. Работает в offline и
> синхронизируется при появлении связи.

### 7. Role-based отчётность

> Сейчас Reports общая. Сделать: для владельца — финансы и P&L,
> для управляющего — operations (occupancy, complaints), для горничной
> — её план уборок, для бухгалтера — выгрузка для 1С/контур.
> Каждой роли свой dashboard на главной.

### 8. Expense Tracking / OPEX-модуль

> Сейчас учёт только выручки. Добавить: зарплаты, коммуналка, прачечная,
> ремонт, амортизация. Каждый расход — приход/чек прикреплённый
> файлом, авто-распределение по объектам (если расход общий — по
> доле выручки). Месячный P&L по объекту автоматом.

### 9. F&B / POS интеграция

> Сейчас счёт только за номер. Подключить ресторан/бар (через iiko,
> R-Keeper, СБИС.POS) → добавлять заказы прямо в счёт номера, чтобы
> гость оплатил всё при выезде. Дополнительные +15-20% выручки.

### 10. Маркетплейс расширений

> Сейчас интеграции жёстко зашиты. Сделать App Store-style каталог:
> сторонние разработчики могут публиковать модули (например, «Чат-бот
> для Telegram с GPT», «Скан паспорта», «Интеграция с Я.Лавкой»),
> отель — включить за подписку. Создаёт экосистему и снижает нагрузку
> на core-команду.

## 4. ❷ 10 функций, которых у нас сейчас НЕТ — must-have для рынка

Это критические возможности, которые есть у конкурентов и которые
ожидаются современным отельером.

### 1. Online Check-in + сканер паспорта (форма 5 / форма 7 МВД)

> Гость до заезда заполняет паспорт через камеру телефона, OCR
> распознаёт ФИО / серия / номер. PMS автоматически формирует
> Форму 5 (для россиян) и Форму 7 (для иностранцев), отправляет в
> МВД через ЕМИАС/КИАС. У Bnovo и Контур.Отель уже есть, у нас нет.

### 2. Электронные замки (TTLock / Igloohome / Salto)

> Гость получает виртуальный ключ в SMS / push после оплаты —
> прикладывает телефон к замку. Уход с физических ключей и стойки
> регистрации. Особенно важно для апартаментов и night-only гостей.

### 3. Revenue Management System (RMS)

> Отдельный модуль (как BEONx или Hotellab): прогноз load на 365 дней,
> what-if симуляция изменения цены, авто-применение цен по правилам,
> отчёты Pace & Pickup.

### 4. Unified Inbox для всех каналов сообщений

> Сейчас сообщения от гостя приходят в Booking inbox, WhatsApp,
> Telegram, email отдельно. Объединить в один экран (как Guesty
> Unified Inbox): нити по гостю, теги, авто-ответы на типовые
> вопросы через GPT.

### 5. CRM-профиль гостя с историей и предпочтениями

> Сейчас есть Guests, но без deep-CRM. Сделать: история всех
> пребываний, любимый номер/этаж, аллергии, предпочтения (доп.
> подушки), сегментация (VIP / repeat / lost), email-кампании.
> Lifetime value на профиле.

### 6. Automated Upsell Engine

> За 24 часа до заезда система автоматически предлагает гостю:
> ранний check-in (+1500₽), поздний check-out, апгрейд в люкс,
> завтрак в номер, бутылка вина. Гость кликает → оплачивает → доход
> идёт сразу. RoomRaccoon показывает +18% дохода на этом.

### 7. Платёжные ссылки (Тинькофф / ЮKassa / Сбер) с автогенерацией

> Сейчас нет онлайн-оплаты вообще. Подключить: при создании брони
> авто-генерация ссылки на оплату, поддержка СБП, рекуррентные
> платежи (депозит → доплата → инцидентал). Чек уходит сразу через
> ОФД.

### 8. Фискализация через Атол / Эвотор / Контур.ОФД

> Каждая оплата должна формировать фискальный чек по 54-ФЗ. Сейчас
> у нас этого нет — для коммерческого использования критично. У
> Контур.Отель / Bnovo интеграция «из коробки».

### 9. eFMS / отчётность в МВД для иностранцев

> Форма уведомления о прибытии иностранного гостя. По закону отель
> обязан подать в МВД в течение 24 часов. Сейчас отельеры
> заполняют вручную → теряют время и риск штрафа 500к. Авто-выгрузка
> на портале услуг.gosuslugi.ru/eFMS — отличить нас от конкурентов.

### 10. Housekeeping Route Optimization

> Когда у горничной 15 номеров на этаже — построить оптимальный
> маршрут (как в логистике): start point → кратчайший обход с
> учётом приоритетов (выезд → новый въезд через час; обычный → когда
> успеете). Экономия ~20 минут на смену × 3 горничных = 1 чел/час
> в день.
